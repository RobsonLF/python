# Criando Projeto Django

1 - Cria o ambiente virtual

	1.1 - python -m venv venv

2 - Ativa o ambiente virtual

	2.1 - .\venv\Scripts\activate.ps1

3 - Instala o Django

	3.1 - pip install django

4 - Criar a pasta do projeto django

	4.1 - django-admin startproject project . (o ponto indica que os arquivos do django serão criados na pasta raiz do projeto)

5 - Iniciar o server

	5.1 - python manage.py runserver
